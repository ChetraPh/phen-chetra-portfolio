# PHEN CHETRA — Personal Portfolio

## របៀបបើក Website
1. Extract `phen_chetra_portfolio.zip` ប្រសិនបើអ្នកទាញយក ZIP។
2. បើក folder `phen_chetra_portfolio` ក្នុង VS Code។
3. បើក `index.html` ក្នុង browser ឬប្រើ VS Code extension **Live Server** រួចចុច **Go Live**។
4. ត្រូវទុក `index.html`, `style.css`, `script.js` និង folder `assets` នៅទីតាំងដូចគ្នា។

## Files
- `index.html` — content និង sections របស់ Portfolio
- `style.css` — Dark Blue responsive design
- `script.js` — mobile navigation និង active section
- `assets/phen-chetra.jpg` — portrait crop ពី CV ដែលអ្នកផ្ញើ

## ចំណាំ
- Email, phone, location, education, roles និង project descriptions ត្រូវបានយកពី CV ដែលបានផ្តល់។
- CV បង្ហាញបទពិសោធន៍ IT Support Intern នៅ Aug–Oct 2024 និង ASP.NET Intern នៅ Jul–Sep 2024 ដែលជាថ្ងៃខុសគ្នា/អាចត្រួតគ្នា។ សូមផ្ទៀងផ្ទាត់កាលបរិច្ឆេទ និងលំដាប់ការងារមុនពេល publish។
- Google Fonts ត្រូវការអ៊ីនធឺណិត។ Website នៅតែអាចដំណើរការបាន ប្រសិនបើគ្មានអ៊ីនធឺណិត ប៉ុន្តែប្រើ font fallback។
- មិនទាន់មាន Resume download button ព្រោះមិនទាន់មានឯកសារ CV PDF ដែលអាចភ្ជាប់បាន។
